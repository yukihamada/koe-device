## 2. ソーラー充電サブシステム配線（ハード設計）

```
  [6V 1-2W ソーラー] ──IN──> [CN3791 MPPT] ──BAT(JST-PH)──> [1S LiPo 1000mAh]
                                                              │
                                                       (LiPo 3.7-4.2V)
                                                              ├──> ESP32-S3 5V/VIN系 or 3V3 LDO入力
                                                              └──> (任意 MAX17048 残量計)
  音声: ESP32-S3 ──I2S──> MAX98357A ──> 8Ωスピーカー
        ESP32-S3 <─I2S── INMP441（マイク）
```

設計メモ:
- CN3791 は**ソーラー入力をMPPTで最大電力点に追従**し1セルLiPoを充電。負荷（ESP32）はLiPoから常時給電（充電と並行可）。
- 屋外日中はパネル出力 > 平均消費 → **充電しながら連続運用**。10hは無日照の予備。
- 屋内/夜は USB-C 充電前提（CN3791はソーラー専用なのでUSB充電は別途TP4056等 or DevKitのUSBで）。
- 量産では `stone/` パック/ランタン筐体の**上面にパネル**（受光面積確保）。

## 3. 10時間・実測手順（実機が来たら）

1. **アイドル平均電流**: USB電流計 or マルチメータをLiPo→ESP32間に直列。ファーム起動・WiFi接続後、待機（録音オフ）で平均mAを5分測定。
2. **受信再生時**: 焚き火ラジオ相当の受信/再生中の平均mA。
3. **送信時**: 録音→送信中の平均mA。
4. **想定デューティで加重平均** → 稼働時間 = 容量(mAh) / 加重平均(mA)。目標: ≥10h（1000mAhなら平均≤100mA）。
5. **ソーラー検証**: 屋外 good sun でCN3791の充電電流を測り、`充電 − 平均消費 > 0`（ネットプラス）を確認。

期待値（[仕様](../docs/TAKIBI_DEVICE_SPEC.md)の概算）: ライトスリープ＋モデムスリープで平均20–30mA → 1000mAhで余裕の10h超。

## 4. firmware 前提（10h保証の土台・別PRで対応）

実測の前に、現ファームの省電力が効くよう修正が要る（[仕様 §3](../docs/TAKIBI_DEVICE_SPEC.md)）:
- `firmware/src/power.rs::set_cpu_80mhz()` → `esp_pm_configure` を実際に呼ぶ（＋ `sdkconfig` で `CONFIG_PM_ENABLE`）
- `enable_modem_sleep()` を `main.rs` から呼ぶ
- これらは**実機ビルド/実測後に確定**（m5にESP-IDFツールチェーン導入中）

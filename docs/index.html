KOE がしてくれること

  • あなたの声で多言語 — 日本語で話す→英語・ポルトガル語をあなたの声のまま
  • 読み間違いを防ぐ — ふりがなを直せる＋whisperで読み返し検証
  • まかせる作文 — ざっくり言うと、ちゃんとした“送る文”に
  • 声のなりすまし対策 — 声はあなたしか使えない（同意登録＋許可制）
